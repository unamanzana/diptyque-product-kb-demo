# 问答评测冒烟基线 v1

## 边界

本记录只包含 `catalog_fact` 分类的前 2 个案例，用于验证评测器、问答 API 和失败归因能正常连通。它不是完整 48 题基线，不能用于判断整体问答质量。

运行时间：2026-07-29。

## 结果

| 案例 | 分数 | 主要失败层 |
| --- | ---: | --- |
| 杜桑系列有哪些产品？请完整列出。 | 29% | provider、intent、retrieval、generation |
| 杜桑淡香水有哪些容量？ | 67% | intent、grounding |

平均自动评分为 48%。

## 已暴露问题

1. “杜桑系列有哪些产品”没有进入确定性的系列完整列表查询，随后本地环境连接模型提供方失败，最终返回空回答。
2. “杜桑淡香水有哪些容量”被错误解释为“淡香水有哪些产品”，返回了全部 25 款淡香水，没有回答 50ML 和 100ML。
3. 当前意图识别优先匹配品型词，缺少“具体商品 + 规格问题”的更高优先级解析。
4. 确定性系列查询对“系列”后缀和“请完整列出”等自然表达覆盖不足。

## 后续使用

- 完整基线应在能访问 DeepSeek 的环境中运行全部 48 题。
- 完整运行前不根据这 2 题修改模型提示词；先获得失败分布，再按最高频根因改造。
- 本地模型提供方网络失败与业务问答失败分开统计，避免混淆。
